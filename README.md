Neon Coast Cover Studio — build an offline web app that turns any photo and caption into GTA 6-style cover art, exported as a PNG to share; an AI judge compares the apps two at a time, places go by win rate, and the 50 best share $250.

Multi-panel cast posters with a hero close-up, striped retro-chrome titles, neon script subtitles, role tags, press quotes, gold seals and billing blocks — all rendered on-device from your own photos, in 1080×1080, 1080×1350 and 1920×1080. No upload, no network, no Rockstar artwork.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in desktop Chrome. Load your photos (or use the built-in samples), pick a layout and a grade, edit the title and cast, and export a PNG.
